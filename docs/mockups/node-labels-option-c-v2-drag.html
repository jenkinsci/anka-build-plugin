Drag behavior

  • Handle on the left of every card header (collapsed or expanded)
  • Dragging reorders the underlying template list (saved with cloud config)
  • In the 2-col grid, order is left→right, then next row — so adjacent order = side by side
  • Clicking the chevron/header toggles expand; drag handle is the only drag target (avoids fighting with text selection)
